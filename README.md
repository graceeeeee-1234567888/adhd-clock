# adhd-clock · Piano Garden

音乐番茄钟：专注计时、练琴任务、奖励、节拍器、实时音准和小星星跟弹。

## 本地打开

请保留整个项目目录：`index.html`、`theme.css`、`particles.js` 以及 `assets/`。打开 `index.html` 即可查看。麦克风功能建议通过本地服务使用：在项目目录运行 `python -m http.server 8765 --bind 127.0.0.1`，然后访问 http://127.0.0.1:8765 。

## 当前主题

Piano Garden 将复古桌面窗口、银色立体按键、蓝天草地、粉彩印刷纹理和乐谱数字融入练琴界面。任务与计时区域使用清楚的文字层级，奖励区有小猫贴纸。

背景星星、泡泡和音符保留鼠标连线交互，可通过“粒子开/关”按钮关闭；后台暂停动画，遵循系统减少动态效果设置，没有滚动联动效果。

`assets/` 中的 JPG/PNG 为用户提供的参考素材原文件副本；`score-pattern.svg` 为本项目编写的装饰性乐谱纹理。素材来源与使用位置见 `assets/README.md`。
