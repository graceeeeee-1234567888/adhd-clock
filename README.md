# adhd-clock

音乐番茄钟：专注计时、练琴任务、奖励、节拍器、实时音准和小星星跟弹。

## 本地打开

将 `index.html` 和 `theme.css` 放在同一目录，打开 `index.html` 即可查看。使用麦克风时，建议在该目录运行 `python -m http.server 8765 --bind 127.0.0.1`，然后访问 http://127.0.0.1:8765 。

## 版本

- `v0.1-original`：原始界面，完整保留在 Git 历史和标签中。
- 新版：黑底、荧光绿与亮粉静态界面，无滚动特效；保留原有功能逻辑。

GitHub 主分支展示最新版本，历史提交仍可查看、下载和恢复。任务进度存在使用者浏览器本地，不会随代码上传。
